# Changelog

## 0.1.0

- Initial release of `tab_animation_pro`
- Regular and irregular `TabBarShape` catalog
- `TabItemShape` and `TabBarSurface`
- Layered indicator / item / feedback / bar-motion animations
- Convenience `TabAnimationStyle` presets
- `enable3D` + `Tab3DStyle`
- External icons/badges via `TabGraphic` / `TabBadge` builders (no Lottie/GIF package dependency)
- Full-platform example with Android release signing aligned to swiper_view_pro style
